# Free Unreal Engine VFX

Free realtime VFX for Unreal Engine by **Vefects**.

## Download

**[Download the latest release](../../releases/latest)**

The release contains separate project ZIPs so you can use only the packs you need.
Download release assets from the Assets section. GitHub's automatically generated
Source code downloads contain repository documentation, not the VFX projects.

## Installation

1. Download and extract the collection, then extract the individual pack ZIP you want.
2. Open the included `.uproject` with the Unreal Engine version specified in `PACKS.csv`.
3. Open the pack's demo map in the Content Browser to explore the effects.
4. To use the assets in an existing project, select the desired asset folders in
   the Content Browser and choose **Asset Actions > Migrate**.
5. Review the dependencies and select your destination project's `Content` folder.
   Follow any setup notes supplied with the original pack.

Back up existing projects before migration. Materials, Niagara, rendering settings
and other requirements can differ between packs. Project engine versions are read
from the supplied `.uproject` files; this collection has not been playtested in
every engine version. Use a copy when converting a project to a newer engine.

## Included packs

See `PACKS.csv` in the release for the complete pack list, project versions and
archive names. Each pack retains its original Unreal project and asset paths.
